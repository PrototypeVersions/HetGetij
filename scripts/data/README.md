# Geographic data

`provinces-2026.topojson` holds generalised outlines of the twelve Dutch provinces (CBS / Kadaster, "provincie_gegeneraliseerd", 2026), as distributed in TopoJSON form by the cartomap/nl project:

- https://github.com/cartomap/nl
- CBS and Kadaster publish this geography as open data under CC BY 4.0.

`world-110m.json` is Natural Earth 1:110m country geometry in TopoJSON form, distributed by the Vega datasets project (https://github.com/vega/vega-datasets). Natural Earth data is public domain.

Outlines are generalised for overview maps. Story markers are approximate reporting locations, not surveyed coordinates. The renderer and labels are original code; no remote map service, tracking or API key is used.
